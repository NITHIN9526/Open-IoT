Connection settings

Use the exact address you will open in your browser, without a trailing slash. For another computer, use this server’s LAN address and port 3000. Internet access requires HTTPS and a separately configured tunnel or reverse proxy.

HTTP and MQTT on your local network are unencrypted. Enable network access only on a trusted network. Google Home also requires the OAuth and project configuration described in the voice setup guide.

Backup and restore

Backups include the database and encryption key. They stay in the protected server folder shown below. Copy complete backup folders to a safe location using administrator access.

    Restore replaces current data and signs everyone out. A recovery backup is created first. Server connection settings stay unchanged.

    Logs and data

    Use the “Open IoT Server Logs” Start Menu shortcut for service logs. Uninstalling preserves your database and backups.
